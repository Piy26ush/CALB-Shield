Unanchored Distribution Overlap

          
The auditor is given an arbitrary model checkpoint θ* with zero knowledge of training data, base model weights, or trigger format.

          
    
            
  • The Boundary: A backdoor is mechanistically a memorized conditional association (rare trigger → target payload). Clean LLMs contain millions of identical associations (verbatim literature, rare syntax, foreign idioms).
    • 
            
  • Identical Distributions: An unconstrained attacker crafts natural triggers matching the clean tail distribution. No black-box statistical test can separate identical distributions.
    • 
            
  • Empirical Witness: 11 evaluated zero-reference detection paradigms all collapsed on physical hardware (e.g. 80% false alarms on benign fine-tunes, identical Δ=0.0000 on embeddings).
