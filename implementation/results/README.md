# CALB-Shield: Empirical Results & Verification Registry

This directory contains all empirical verification artifacts, behavioral probe fingerprints, cross-architecture benchmarks, repeatability logs, and cryptographic admission records for the **CALB-Shield** framework.

---

## Directory Organization

```
implementation/results/
├── README.md                      ← Directory index, provenance, and experimental documentation
├── fingerprints/                  ← Empirical 180-dim behavioral feature vectors & normalizer baselines
├── evaluations/                   ← Interactive single-checkpoint admission audit reports (JSON)
├── physical_benchmarks/           ← RQ1 Physical cross-architecture transfer matrices (CSV)
├── repeatability/                 ← Phase 5 Exp 1: 5-run repeatability & variance verification (CSV/JSON)
├── lopo_benchmark/                ← Phase 1F: 5-fold Leave-One-Pretrained-Out evaluation (CSV/JSON)
├── spectral_scans/                ← RQ2: QR-SVD singular value spectra & rank-1 collapse logs (CSV)
└── aibom/                         ← Stage 4: SPDX-AI 3.0 cryptographic admission certificates (JSON)
```

> **Backward Compatibility Notice:** Relative symbolic links are maintained at the root of `implementation/results/` so that any legacy scripts or absolute path references continue to function transparently without modification.

## 5. Expanded LOPO Benchmark (`lopo_benchmark/`)

Leave-One-Pretrained-Out cross-validation across 5 architecture families (`llama3`, `mistral`, `qwen`, `gemma`, `phi3`).

> **Methodological Scope Notice:** Uses a synthetic perturbation-expanded cohort (100 instances) anchored directly on physical LLaMA-3, Mistral-7B, and Qwen-1.5B (Clean and Trojan PoC) checkpoints.

| Artifact File | Format | Key Metrics |
|---|---|---|
| `lopo_evaluation_results.csv` | CSV Table | Per-classifier macro metrics: Logistic Regression (100% AUC, 1.000 F1), Linear SVM (100% AUC, 1.000 F1), Random Forest (100% AUC, 1.000 F1). |
| `lopo_evaluation_summary.json` | JSON Object | Complete per-fold breakdown across all 5 held-out architectures. |
